Neon Bay Heat — a complete 3D open-world action/driving game inspired by GTA 6 (Vice City / Leonida), built with Three.js (vendored, zero network requests). Neon Bay city with beachfront art-deco hotels, downtown, port and park, day/sunset/night cycle, on-foot play plus 6 vehicles (supercar, muscle car, taxi, police cruiser, armored truck, speedboat) with arcade driving physics, drift and nitro, a 0–5 star wanted system with police pursuit, roadblocks and helicopters, 4 weapons, 5 story missions (race, getaway, heist, boat run, time trial) plus stunt jumps, GTA-style HUD with radar minimap, and 3 procedural Web Audio radio stations. Runs at a fixed 60 Hz timestep with zero console errors.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser and press PLAY.
